- [ ] **Add a Prettier check to CI.** Add a `format:check` script and a CI step ([plan-01 §5](../plan-01.md#5-formatting-and-housekeeping)). Done when CI fails on an unformatted file.
- [ ] **Get react-grid-layout out of the entry chunk.** Add `"sideEffects": ["**/*.css"]` to `package.json`. If the grid is still in the entry chunk, have the route loaders import from `api/queries` directly. No `React.lazy` ([plan-01 §1](../plan-01.md#1-bundle-get-react-grid-layout-out-of-the-entry-chunk)). Done when `dist/assets/index-*.js` contains no `react-draggable`, and tests and Storybook still pass.
- [ ] **Decide on the chunk-size warning.** Record the new entry size. If it's still over 500 kB, lazy-load Spotlight or split vendor code, or raise `chunkSizeWarningLimit` with a comment. Done when the build has no warning, or the warning is documented.
- [ ] **Hold `<main>` during a window resize.** Add a resize listener to `useMainLock` using Mantine `useWindowEvent('resize')` and `useDebouncedCallback(release, 150)`. It reacts to width changes only and shares `generation` with `holdFor`. Done when `useMainLock.test.ts` covers: height-only resize (no pin), a resize while a panel is moving, and release after the debounce.
- [ ] **Measure `<Activity>` for far tiles before building it.** Prototype a hide margin of about 2 viewport heights with the skeleton shown next to the hidden content, and compare one width change on `/dashboards/perf` ([plan-01 §3](../plan-01.md#3-far-off-screen-tiles-in-activity-measure-before-building)). Done when the numbers are in `docs/grid-and-charts.md` and the go/no-go decision is written down.
- [ ] **Add the reduced-motion setting.** Add a `motion: 'system' | 'reduce'` field (defaults to `system` through the store's `merge`), generalize the `dirty` check in `useAppearanceForm`, add a `useMotion()` hook built on Mantine's `useReducedMotion`, and set `data-motion` on `<html>`. Done when the tests cover the setting, the hook and the attribute, and charts and pane transitions respect it.
- [ ] **Spike: force Mantine transitions off.** Check whether `[data-motion='reduce']` CSS is enough for Mantine `Transition`. If not, set `transitionProps.duration` through the theme. Done when a Drawer opens instantly with the setting on and the OS setting off.
- [ ] **Trace the panel slide and breakpoint crossing.** Production build, `/dashboards/perf`. Done when the "Measured" column in `docs/grid-and-charts.md` is filled in: no long task inside the 180 ms slide, and the number of chart resizes when a toggle crosses a breakpoint.
