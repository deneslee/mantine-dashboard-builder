# Phases

This page lists the phases in order, with links. It owns the phase order and each phase's status. Each phase file owns its goal, its candidate gaps and its steps. The current phase and the next action are on the [start page](../README.md).

**Status of the plan:** the planning system was approved on 2026-11-22 (P0). The phases themselves are still a proposal. [ADR-0001](../../adr/0001-green-baseline-before-moves.md) decides whether P2 comes before P4, and each phase is confirmed when it starts.

**Order.** Phases run in order. Restructuring (P4) is kept apart from functional redesign (P6): P4 moves code without changing behaviour.

The "Needs decisions" column gives ADR numbers ([index](../../adr/README.md)).
