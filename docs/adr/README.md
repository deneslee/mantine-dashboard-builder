# Architecture decision records

This is the index of accepted architecture decisions. The queue of open decisions is [../restructure/decisions.md](../restructure/decisions.md).

**How ADRs are written** (`ecc:architecture-decision-records`):

- An ADR is written only once you accept the decision, and you see the draft first.
- **File name:** `NNNN-kebab-title.md`.
- **Header:** Date, Status, Deciders.
- **Sections:** Context (10 lines or fewer), Decision, Alternatives Considered, Consequences.
- **Statuses:** `accepted`, `deprecated`, or `superseded by ADR-NNNN`. `proposed` is not used here, because open decisions stay in the queue.
- An ADR that records an older choice after the fact is marked "reconstructed", with the original date if known.
